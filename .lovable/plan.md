
# Make Mock Portfolio the Hero Feature

Today the page is gated behind sign-in with a bare empty state, no public proof of value, no reason to come back, and nothing shareable. Below is a phased plan to flip it into the strongest acquisition + retention surface on the site.

## Problem (why it isn't pulling weight today)
- Anonymous visitors see only "Sign In" — zero proof of value before the wall.
- No leaderboard, no streaks, no notifications → no reason to return.
- No social/embeddable artifact → no organic acquisition loop.
- Single mock mode only; no comparison vs benchmarks, no scenarios, no goals.
- Discoverable from sidebar only; never surfaced from fund pages where intent is highest.

## North-Star Metrics
- D7 portfolio retention, # portfolios created/week, avg holdings per portfolio, share-link CTR → sign-up conversion, % funds with "Add to portfolio" click.

---

## Phase 1 — Open the front door (acquisition)
Goal: anyone can play immediately; sign-in moves to a save/persist moment.

1. **Public demo mode** — Portfolio works without auth using localStorage. Soft-prompt "Save your portfolio" CTA appears after 2nd holding added.
2. **One-click starter portfolios** — "Conservative MMF stack", "Diaspora USD income", "NSE bluechips", "Diversified 60/30/10". Each pre-populates 3-5 holdings using real KFF data.
3. **"Add to Portfolio" buttons** on every Fund detail, Stock detail, and Compare row. Adds straight to mock (logged-in or demo).
4. **SEO landing** — `/portfolio` gets a real hero (mock dashboard preview, "Try without signing up", starter pack CTAs) + meta tags + JSON-LD `WebApplication`.

## Phase 2 — Depth that justifies returning (retention)
1. **Benchmarks line** on the value chart — overlay vs MMF average, NSE 20, and inflation. Answers "am I actually winning?".
2. **Goals & projections** — set a target (e.g. "KES 1M in 24 months"), compound forward at current blended yield, show progress ring + months-to-goal.
3. **Scenario / what-if** — "What if I moved 50% from MMF to NSE bluechips?" toggle that re-runs allocation and projects forward.
4. **Tax-aware net yield** — apply the 15% withholding rule (already a project rule) so the "real take-home" number is the headline KPI.
5. **Smart alerts** (reuses existing `price_alerts` + notifications) — "Your MMF yield dropped 0.4%", "Portfolio crossed KES 100k", "Goal 25% reached". Email + in-app.

## Phase 3 — Social loops (acquisition + virality)
1. **Public share link** `/p/<slug>` — read-only snapshot with allocation pie, total value masked or shown (user choice), watermark. OG image generated by an edge function so WhatsApp/X previews look beautiful.
2. **Weekly leaderboard (opt-in, anonymized handles)** — best % return, best yield/risk score, biggest streak. CMA-compliant: no real money, "mock" badge everywhere.
3. **"Compare with a friend"** — paste two share links, see side-by-side allocation/yield.
4. **Embed widget** — small iframe of allocation + yield for users who blog/post on socials.

## Phase 4 — Habit loops (engagement)
1. **Daily streak** — opening the portfolio extends streak; small icon in nav.
2. **Weekly digest email** (Resend already wired) — "Your week: +0.12% • MMF lead • next goal check-in in 14 days".
3. **Achievements** — first holding, 5 asset classes, hit goal, beat MMF benchmark for 30d. Pure motivational, no money.

## Phase 5 — Trust & compliance (always-on)
- "MOCK" watermark on every shared artifact and chart.
- Footer disclaimer reused (15% WHT note already mandatory).
- No "TOP" yield labels on leaderboards (existing compliance rule).
- Robots: keep `/p/<slug>` indexable; keep authed `/portfolio` `noindex` if PII-bearing.

---

## Build order recommendation
Ship Phase 1 first — it's the highest-leverage move (kills the sign-in wall, adds 4 entry points, gives SEO a real page). Then Phase 3 share links (viral loop) and Phase 2 benchmarks/goals (depth) in parallel. Phases 4–5 are polish.

## Technical notes
- Demo mode: extract `usePortfolio` into a storage adapter (`supabaseAdapter` vs `localAdapter`); same hook signature, swapped by `useAuth`.
- Starter portfolios: a JSON catalog in `src/data/starterPortfolios.ts` referencing fund slugs / stock tickers, hydrated client-side.
- Share links: new `public_portfolio_snapshots` table (id, slug, payload jsonb, created_by, is_public, created_at) + edge function `og-portfolio` for OG image (reuse pattern from existing `og-meta`).
- Benchmarks: nightly cron computes MMF avg + NSE20 series (we already snapshot fund + stock history daily).
- "Add to portfolio" button: tiny shared component reading the demo/auth adapter.
- Streaks/achievements: add `portfolio_engagement` table (user_id, last_open_date, streak, achievements jsonb).
